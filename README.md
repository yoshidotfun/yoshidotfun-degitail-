# degitail サイト

岡山のデジタルサポート「degitail」の静的サイトです。ビルドや追加パッケージは不要で、HTMLをそのまま公開します。

## 共通デザイン（site.css）

- `site.css` は、勉強会ページ `workshop.html` の白黒デザイン（黒帯のヒーロー、太字見出し＋2pxの下線、四角いボタン、2px枠のカード、黒いフッター）に通常ページを揃えるための上書きCSSです。
- 通常ページ（`flyer*.html` と `workshop.html` 以外の全HTML）は、各ページの `<style>` の**直後**で `<link rel="stylesheet" href="site.css">` を読み込んでいます。後から読み込むことで、各ページ固有のCSSを消さずに上書きしています。
- 新しいページを追加するときも、`</style>` の直後に同じ1行を入れてください。

## 勉強会申込を Google スプレッドシートに自動記録する

`workshop.html` の申込フォームは、設定すると **1申込＝1行** で Google スプレッドシートに追記されます。受信側は `workshop-sheets.gs`（Google Apps Script：Googleのサービス上で動く小さなプログラム）です。

### 動作のしくみ

| `workshop.html` の `SHEETS_URL` | 送信先 |
|---|---|
| 空欄 `''`（初期状態） | これまでどおり Formspree（メール通知） |
| Apps Script のURLを設定 | Google スプレッドシート |

二重登録の防止：

- 確認画面に進むたびに「申込ID」を1つ作ります。送信に失敗して再送信しても同じIDが使われます。
- スクリプト側は同じ申込IDの行がすでにあれば追記しません。同時に届いた送信も1件ずつ順番に処理します。
- 送信中はボタンを押せないため、二重クリックでは送信されません。

### 設定手順（初回のみ・約10分）

1. Google ドライブで新しいスプレッドシートを作ります（名前の例：`勉強会申込`）。
2. メニューの **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消して、`workshop-sheets.gs` の中身を貼り付け、保存します。
4. 右上の **デプロイ → 新しいデプロイ** を開き、歯車アイコンから種類 **ウェブアプリ** を選びます。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. **デプロイ** を押し、Googleアカウントでアクセスを承認します。「このアプリは Google で確認されていません」と出た場合は **詳細 → （プロジェクト名）に移動** で進めます（自分で作ったスクリプトのためです）。
6. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）をコピーします。
7. `workshop.html` の次の行にURLを貼り付けて公開します。

   ```js
   const SHEETS_URL = 'https://script.google.com/macros/s/……/exec';
   ```

8. 公開したページからテスト申込を1件送り、スプレッドシートに **申込一覧** タブと1行が追加されることを確認します（テスト行は削除してかまいません）。

スクリプトを修正したときは **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン → デプロイ** で更新します。この方法ならURLは変わりません。

元に戻すとき（Formspreeへ戻す）は、`SHEETS_URL` を `''` に戻すだけです。

### 記録される列

| 列 | 項目 | 内容 |
|---|---|---|
| A | 受付日時 | スプレッドシートが受け取った日時 |
| B | 申込ID | 二重登録防止用のID（削除・変更しないでください） |
| C | スレッズ名 | 例：`@your_threads_name` |
| D | メールアドレス | |
| E | コース | 初級者向けコース／中級者向けコース |
| F | 希望AI | Claude Code／Codex |
| G | 希望日程 | 複数選択は「・」区切り。未選択は「（未選択）」 |
| H | AI経験 | |
| I | 支払い方法 | 当日払い／事前払い／紹介割（事前払い） |
| J | 参加費 | 2,000円／1,800円／1,500円 |
| K | 紹介者 | 紹介割のときのみ |
| L | 作りたいもの | |
| M | 質問・要望 | |
| N | 送信日時(端末) | 申込者の端末で送信した日時（ISO形式） |

- 1行目は見出しで、固定表示になります。
- `=` `+` `-` で始まる入力は、数式として実行されないよう先頭に `'` を付けて文字として保存します（シート上では `'` は表示されません）。
- 1項目は最大2,000文字です。

### Excel / CSV で使う

**Excelで開く（おすすめ）**
スプレッドシートで **ファイル → ダウンロード → Microsoft Excel (.xlsx)**。そのままExcelで開けます。

**CSVで使う**
1. **申込一覧** タブを開いた状態で **ファイル → ダウンロード → カンマ区切り形式 (.csv)**（開いているタブだけが出力されます）。
2. CSVをダブルクリックでExcelに開くと、日本語が文字化けしたり、`@` で始まる値がエラーになったりすることがあります。Excelでは次の手順で読み込んでください。
   - Excelで空のブックを開く → **データ → テキストまたはCSVから** → ダウンロードしたCSVを選ぶ
   - 「元のファイル」を **65001: Unicode (UTF-8)** にして **読み込み**

### 補足

- スプレッドシートに記録する設定の場合、Formspreeのメール通知は届きません。通知が必要なら、スプレッドシートの **ツール → 通知設定 → 通知を編集** で「変更が加えられたとき」にメールで通知するよう設定してください。
- スプレッドシート自体は作成者だけが見られます。ただしウェブアプリのURLを知っている人は送信できるため、URLはページ以外で公開しないでください。
- `workshop.html?admin=1` の管理画面は Claude のアーティファクト環境専用です。公開サイトでの申込一覧はスプレッドシートで確認してください。

## 事前払いを Stripe Payment Links で受け付ける

`workshop.html` は、申込の保存に成功した後、事前払い（1,800円）・紹介割（1,500円）を選んだ人に「予約完了・お支払い待ち」画面を出し、約1.5秒後に Stripe のお支払いページへ移動します（移動しない場合のボタンも表示）。当日払いの動きは変わりません。

Payment Links（ペイメントリンク：Stripe が用意するお支払いページのURL）を使うので、サーバーや追加パッケージは不要です。

> **秘密鍵（`sk_live_…` / `sk_test_…`）や Webhook シークレット（`whsec_…`）は絶対に `workshop.html` に書かないでください。** 貼るのは `https://buy.stripe.com/…` の公開URLだけです。

### 設定手順

1. Stripe ダッシュボード右上の **テストモード** をオンにします。
2. **商品カタログ** で商品を2つ作ります。どちらも **一括（1回限り）**・通貨 **JPY**。
   - 勉強会 事前払い：1,800円
   - 勉強会 紹介割（事前払い）：1,500円
3. **Payment Links → 新規作成** で、それぞれの商品のリンクを作ります。
   - 数量の変更は不可のままにします。
   - 任意：**支払い後** の設定で「顧客をウェブサイトにリダイレクトする」を選び、`https://（公開URL）/workshop.html` を指定すると、支払い後に勉強会ページへ戻ります。
4. 作成された `https://buy.stripe.com/test_…` のURLを `workshop.html` の次の行に貼ります。

   ```js
   const STRIPE_LINK_PREPAID_1800 = 'https://buy.stripe.com/…';   // 事前払い 1,800円
   const STRIPE_LINK_REFERRAL_1500 = 'https://buy.stripe.com/…';  // 紹介割（事前払い）1,500円
   ```

5. 公開ページからテスト申込を送り、テストカード `4242 4242 4242 4242`（有効期限は未来の日付、CVCは任意の3桁）で支払えることを確認します。
6. 本番に切り替えるときは、テストモードをオフにして同じ2つのリンクを本番用に作り直し、URLを差し替えます（テスト用URLは本番では使えません）。

`https://buy.stripe.com/` 以外のURLや空欄のときは自動移動せず、予約は通常どおり完了し、「お支払い方法は別途メールでご案内します」と表示します。

### 支払いの確認について

- 静的サイト（サーバーのないサイト）では、支払いが本当に完了したかを安全に確かめられません。リダイレクトで戻ってきたことは支払いの証明になりません。
- 入金の確認は **Stripe ダッシュボードの「支払い」** で行い、スプレッドシートの申込と照合してください。Payment Link は全員共通のURLで、申込IDやメールアドレスは決済に引き継がれません。照合は、お支払いページで入力されたメールアドレス・金額・日時を手がかりに行ってください。
- 自動で照合したくなったら、将来 Webhook（Stripe から支払い完了を通知してもらう仕組み）を受けるサーバー側の処理が必要です。
